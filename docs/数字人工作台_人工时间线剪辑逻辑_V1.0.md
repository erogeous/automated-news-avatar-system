# 数字人工作台：人工时间线剪辑逻辑 V1.0

## 目标

在浏览器中提供一条与常见剪辑软件相似的完整时间线。完整粤语配音是锁定的时间基准，编辑人员通过拖动新闻图片、新闻视频、数字人片段和包装动画，决定它们在成片中的出现时间、持续时间和显示方式。FFmpeg 只负责后台渲染。

## 时间线结构

时间尺以完整配音的 `00:00.000` 为起点，并显示当前播放头。第一版设置五条轨道：

1. **配音主轨**：完整音频波形，默认锁定；允许试听，不允许误删或改变整体时间。
2. **数字人轨**：按原音频切片时间放置 HeyGen 视频，可选择哪些时段显示主播。
3. **新闻素材主轨**：图片和视频可从素材库拖入，允许裁切、移动、替换和排序。
4. **动画与包装轨**：标题条、数据卡、地图、关键词、转场及节目包装。
5. **字幕轨**：由配音时间码生成，允许修字和调整单条字幕边界。

同一时刻只有一个“新闻素材主画面”，但动画与包装可以叠加。配音主轨始终连续。

## 每个素材片段的人工设置

每个时间线片段保存以下信息：

- `start`：相对完整配音的开始秒数。
- `duration`：显示时长。
- `trimIn`、`trimOut`：视频素材的入点和出点。
- `displayMode`：`window`（演播室素材窗）、`fullscreen`（全屏素材）、`overlay`（叠加动画）。
- `transitionIn`、`transitionOut`：无、淡入淡出、溶解等。
- `fit`：填充、完整显示或裁切。
- `muted`：新闻原视频声音默认关闭；人工可打开并设置音量。
- `caption`：供编辑识别的镜头说明，不进入成片。
- `sourceId`：对应素材库文件，保证项目可恢复。

移动片段改变 `start`；拖动左右边缘改变时长或裁切点。所有时间以毫秒保存，界面显示到帧或 0.1 秒。

## 画面模式

### 演播室素材窗

数字人仍在画面右侧，新闻素材显示在左侧素材窗。适合普通新闻图片、数据图和短视频。素材窗的位置和大小使用节目默认模板，必要时可逐片调整。

### 全屏素材

新闻图片或视频覆盖整个画面，数字人暂时隐藏，配音继续播放。适合现场视频、关键画面、地图和需要看清文字的数据图。片段结束后自动恢复演播室布局。

### 动画叠加

数字人或新闻主画面继续显示，在上方叠加标题、关键词、数字、箭头、地图标注等动画。动画片段有独立的开始时间和持续时间。

## 人工剪辑流程

1. 完成稿件、配音和数字人分段生成。
2. 系统用稿件段落和音频切片生成一个初始时间线。
3. 编辑人员播放配音，将素材从右侧素材库拖到相应语句的位置。
4. 对每个素材选择“素材窗”“全屏”或“动画叠加”。
5. 拖动片段和边缘，使画面切换点与口播内容匹配。
6. 使用时间线预览检查节奏；需要时修改入点、出点、转场和原视频音量。
7. 点击“生成预览”，后台以较低分辨率快速渲染。
8. 确认后点击“导出成片”，FFmpeg 按最终时间线生成正式 MP4。

## 自动能力与人工权限

系统自动提供初始方案，包括按稿件顺序排列素材、按完整句子分配时间、默认素材窗布局和基础淡入淡出。人工操作始终具有最高优先级。重新运行自动匹配时必须提示是否覆盖已手工调整的片段。

动画不由模型直接决定最终位置。模型可以根据稿件提出“建议动画”标记，例如人物姓名、重要数字、赛事比分和地点，但编辑人员决定是否采用、何时出现和使用哪一种样式。

## 第一版必须实现

- 音频波形、时间尺、播放头和同步预览。
- 素材库拖入时间线。
- 片段左右拖动、边缘缩放、删除、复制和替换。
- 素材窗与全屏两种显示模式。
- 数字人轨的显示与隐藏区间。
- 淡入淡出或无转场。
- 吸附到句子、字幕、音频切片边界。
- 撤销、重做和自动保存。
- 低清预览与正式导出。

## 第二阶段

- 标题条、数据卡、关键词等动画模板。
- 视频原声与配音的自动压低和恢复。
- 多层素材、画中画、关键帧位置与缩放。
- 稿件句子和时间线片段双向定位。
- 模型建议的素材匹配点和动画候选点。

## 后端时间线数据

项目保存一个可版本化的 `timeline` 对象，而不是只保存顺序和累计时长：

```json
{
  "duration": 248.4,
  "tracks": [
    { "id": "voice", "kind": "audio", "locked": true, "clips": [] },
    { "id": "avatar", "kind": "avatar", "clips": [] },
    { "id": "visual", "kind": "media", "clips": [] },
    { "id": "graphics", "kind": "graphics", "clips": [] },
    { "id": "captions", "kind": "captions", "clips": [] }
  ],
  "revision": 1
}
```

提交合成时，服务器校验片段不越界、视频裁切点有效、素材文件仍存在，再将时间线转换为 FFmpeg filter graph。渲染任务保留所使用的时间线版本，使成片可以复现和回退。

## 与当前系统的关系

现有系统已经具备素材库、分镜顺序、素材时长、口播提示、数字人分段、画面布局参数和 FFmpeg 合成任务。下一步需要把现在的“分镜列表＋自动合片”升级成上述多轨时间线，并让 FFmpeg 接收每个片段的绝对开始时间、裁切点、显示模式和转场参数。

## 最终合片与本地精剪通路

最终流程不再接入第三方在线剪辑中转，保留两个直接出口：

1. **服务器 FFmpeg 自动合片**：根据本期绝对时间线直接输出可发布的 1920×1080 成片。完整配音是唯一音频主轨；数字人出镜时新闻素材在左侧小窗显示，数字人不出镜时新闻素材全屏显示。
2. **本地剪辑包**：自动成片完成后，将同一时间线及全部源资产打包下载。编辑人员可在剪映、Premiere 或 Final Cut 中调整开始点、持续时间、层级、全屏/画中画方式，并补充只存在于本机的素材。

每期本地剪辑包至少包括：

- 完整粤语配音一条，作为锁定主时间基准；
- 按原始时间码排列的全部 HeyGen 数字人视频切片；
- 已下载的新闻图片和视频，以及人工上传的补充素材；
- 由确认后的粤语稿生成、并按最终 MP3 停顿校验的 SRT 字幕；
- 节目片头、循环背景、透明 Logo 和主播人名条。

工作台保存合片输入、字幕、素材对应关系、FFmpeg 任务状态及本地剪辑包地址。自动合片与本地精剪都从同一条主时间线出发，避免两套成片规则漂移。
