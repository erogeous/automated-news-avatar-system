# 《點觀香港》字幕制作规则 V1.0

## 工作台采用的规则

- 字幕正文只取自已确认的粤语配音稿，不用语音识别结果替换文字。
- 最终 MP3 保存后分析真实静音和停顿，字幕边界吸附到邻近停顿；合片前必须通过时码校验。
- 每条字幕最多两行，每行最多 16 个汉字；单条最多 30 个可见字符。
- 优先按句号、问号、感叹号断句，其次按逗号、顿号、分号和冒号断句。
- 保持语义单位完整，不拆开姓名、机构名、地名、日期、数字与量词，不留下单字孤行。
- 字幕不得重叠、倒序或超过最终配音长度。横屏自动成片直接烧录同一份已校验字幕，本地剪辑包也导出相同 SRT。

## 公开规范依据

- BBC Subtitle Guidelines：横屏字幕建议最多两行；字幕和行应在逻辑位置断开，理想位置是句号、逗号或破折号等标点；语言完整性优先于几何平均；字幕应尽量跟随实际语速与发声。
  - https://www.bbc.co.uk/accessibility/forproducts/guides/subtitles/
- Netflix Partner Help Center：多数语言建议将单行控制在约 42 个字符以内，核心目标是避免文字逼近画面边缘。中文新闻采用更保守的每行 16 个汉字，以适配 1920×1080 的大字号双行字幕。
  - https://partnerhelp.netflixstudios.com/hc/en-us/articles/215274938-What-is-the-maximum-number-of-characters-per-line-allowed-in-Timed-Text-assets

## 人工复核清单

1. 试听日期、数字、金额、姓名、机构名与英文缩写。
2. 抽查开场、每个新闻转场和结尾的字幕出入点。
3. 确认没有一字独占一行、上下句语义被拆开或标点悬空。
4. 确认字幕不遮挡主播人名条、新闻画面关键文字及节目 Logo。
5. 合片任务显示“字幕时码已校验”后才允许生成最终成片。
